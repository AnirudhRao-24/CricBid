# CricBid

CricBid is a real-time Cricket Auction web application that lets you and your friends host and participate in live fantasy cricket auctions. 

## Features
- **Live Bidding**: Experience a real-time bidding system built using Firebase Firestore.
- **Role-based Authentication**: Start an auction room as a Host, or join as a Participant to bid on players.
- **Timer Synchronization**: An accurate, synchronized countdown timer ensuring fair play for everyone across the network.
- **Budget Tracking**: Built-in purse management prevents participants from over-bidding.
- **Integrated Voice/Video & Chat**: Communicate with your auction room without leaving the platform using PeerJS (WebRTC) and Firebase chat.
- **AI Coach**: Seek real-time advice from the built-in AI assistant.

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla ES6)
- TailwindCSS (Styling)
- Firebase (Firestore & Authentication)
- PeerJS (WebRTC Voice/Video integration)
